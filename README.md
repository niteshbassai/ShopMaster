# ShopMaster

ShopMaster is an e-commerce web application designed to help users browse products, view details, and add items to their shopping cart. This project is built using PHP, MySQL, HTML, CSS, and JavaScript.

## Features
- **Homepage**: Displays the products and features of the website.
- **Product Detail Page**: Users can see detailed information about the products.
- **Admin Dashboard**: Admin can manage products, add new products, and view all products.
- **Responsive Design**: The site is responsive and works well on both desktop and mobile devices.
- **User Authentication**: Admins can register and log in to the admin section.
- **Add to Cart**: Users can add products to the shopping cart.

## Technologies Used
- **PHP**: For server-side scripting and database interaction.
- **MySQL**: For database management to store product details and user information.
- **HTML/CSS**: For designing the layout and styling the pages.
- **JavaScript**: For basic client-side functionality (no jQuery used).
- **SSH**: For secure connection to GitHub for version control.

## Setup Instructions

1. **Clone the Repository**:
   ```bash
   git clone git@github.com:niteshbassai/ShopMaster.git
2. Install Dependencies:

   Ensure you have a PHP server running (like XAMPP or MAMP).

   Set up a MySQL database and configure the database.php file with your credentials.

3. Database Setup:

   Create a MySQL database and import the necessary tables for products and admin users. You can find the SQL schema in config/database.sql.

4. Running the Application:

   Navigate to the project directory and start the server:

   php -S localhost:8000


Open your browser and go to http://localhost:8000 to see the application.
